# AI SEO Content Automation

Automated SEO content generation using N8n + Google Gemini

## Features
- ✅ Generates SEO-optimized titles
- ✅ Saves to Google Sheets  
- ✅ Uses free Google Gemini API
- ✅ Easy to customize prompts

## How to Setup

1. **Download the workflow.json file**
2. **Open N8n** and import the workflow
3. **Add Google Gemini API key** (free from aistudio.google.com)
4. **Add Google Sheets** (optional for data storage)
5. **Execute the workflow!**

## Tech Stack
- **N8n** - Workflow Automation
- **Google Gemini API** - Free AI for content generation
- **Google Sheets** - Store generated content

## How to Use
- Enter a topic (e.g., "fitness tips")
- AI generates 5 SEO-optimized titles
- Results save to Google Sheets
